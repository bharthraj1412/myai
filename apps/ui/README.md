# AG3NT Web Dashboard (UI)

Next.js-based web dashboard for real-time chat, artifact management, and system configuration.

## Quick Overview

| Aspect | Details |
|--------|---------|
| **Framework** | Next.js (React, TypeScript) |
| **Port** | 3000 (default, configurable) |
| **Role** | Web interface for user interaction with AG3NT |
| **Key Features** | Real-time chat, artifacts, skills browser, MCP manager, system monitoring |
| **Build** | ~2 min production build, ~100MB dist |

---

## Prerequisites

- **Node.js** 18.x or higher
- **pnpm** 8.x or higher
- **Gateway** running on port 18789
- **Agent Worker** running on port 18790

---

## Installation

### 1. Install Dependencies

```bash
cd apps/ui
pnpm install
```

### 2. Set Environment Variables

Create `.env.local` in `apps/ui/`:

```bash
# Gateway API endpoint
NEXT_PUBLIC_AG3NT_GATEWAY_URL=http://127.0.0.1:18789
AG3NT_GATEWAY_URL=http://127.0.0.1:18789  # Backend-only

# Backend path (for daemon spawning)
AG3NT_BACKEND_PATH=/path/to/AG3NT-main
AG3NT_PYTHON=<path-to-python-executable>
AG3NT_DAEMON_SCRIPT=python/deepagents_daemon.py

# Development
NEXT_PUBLIC_DEBUG=false
PORT=3000
```

See `.env.example` for full template.

---

## Running

### Development Mode

```bash
cd apps/ui
pnpm dev

# Output:
# ▲ Next.js x.xx.x
# - Local:        http://localhost:3000
# - Environments: .env.local
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

**Wait 5-10 seconds** for the daemon to initialize on first request.

### Production Mode

```bash
cd apps/ui
pnpm build
pnpm start
```

### Docker

```bash
docker build -f apps/ui/Dockerfile -t ag3nt-ui .
docker run -p 3000:3000 -e NEXT_PUBLIC_AG3NT_GATEWAY_URL=http://gateway:18789 ag3nt-ui
```

## Features

### 1. Real-Time Chat

- **Streaming responses** - Text appears as it's generated by the LLM
- **Markdown rendering** - Code blocks, formatting, syntax highlighting
- **File attachments** - Upload documents, images
- **Audio input** - Speak messages using browser speech recognition
- **Model selection** - Switch between Claude, GPT, etc. mid-conversation

### 2. Artifact Library

- **Code snippets** - View and copy code blocks
- **Documents** - Text, Markdown, HTML renders
- **Images** - Image preview and download
- **Metadata** - Timestamps, model used, context window

### 3. Skills Browser

- **Browse available skills** - (app-launcher, web-research, voice-tts, etc.)
- **Enable/disable skills** - Toggle skill capabilities
- **View skill details** - Description, parameters, examples

### 4. MCP Server Manager

- **Connect MCP servers** - Register and manage Model Context Protocol servers
- **Configure resources** - Set up server endpoints and credentials
- **Monitor status** - Check connection health

### 5. System Monitoring

- **Agent health** - Monitor worker status and memory usage
- **Gateway status** - Check connection to routing daemon
- **System logs** - View real-time events and errors

## Troubleshooting

### Issue: Daemon Not Starting

**Symptom**: "DeepAgents daemon exited (code=1)"

**Solution**:
1. Check Python is installed: `python --version`
2. Check daemon script exists: `ls python/deepagents_daemon.py`
3. Check .env variables: `cat apps/ui/.env.local`
4. View logs: Enable `DEBUG=ag3nt:*` and retry

```bash
DEBUG=ag3nt:* pnpm dev
```

### Issue: Port 3000 Already in Use

**Solution**:
```bash
pnpm dev --port 3001
# Or set in .env.local:
PORT=3001
```

### Issue: No Message Response

**Check**:
1. Gateway running? `curl http://localhost:18789/api/health`
2. Agent worker running? `curl http://localhost:18790/health`
3. API keys configured? Check `.env`
